# mini-jira
A project to refresh my java 21/Spring Boot skills and learn Angular.
Taking the opportunity to test Claude code.
Trying VSCode for the first time for Maven / Java / Spring Boot dev... instead of IntelliJ, for a change.

Uses a postgresql db to store users, projects and taks. 
I used a docker container : docker run --name devboard-db -e POSTGRES_DB=devboard -e POSTGRES_USER=devboard -e POSTGRES_PASSWORD=devboard -p 5432:5432 -d postgres:16
